# 家計簿アプリ (KakeiboGX)

日々の支出・収入を記録し、カレンダー・カテゴリ別レポート・予算管理までを行う家計簿アプリです。

**Android アプリ**と**PC（Windows）アプリ**の2つのクライアントがあり、Google Drive 上の1つの JSON ファイルを共有することで、外出先ではスマホ、腰を据えた集計・修正はPC、という使い分けができます。

```
   Android (Kotlin / Compose)            PC (Python / CustomTkinter)
   Room DB ──┐                                    ┌── メモリ上のデータ
             │                                    │
             └──> kakeibo_sync.json <─────────────┘
                  (Google Drive)
             Drive API v3          Drive for Desktop のマウント先を直接読み書き
```

---

## Android 版

### 入力画面
- **支出 / 収入の記録**: タブで切り替え。
- **日付選択**: 前日・翌日ボタンに加え、日付表示をタップして日付ピッカーを開けます。今日以外の日付を選んでいる場合は警告表示と「今日に戻る」導線が出ます。
- **金額入力（ビルトイン電卓）**: ボトムシート型の電卓UI。
- **カテゴリ選択**: アイコンと色つきのカテゴリリストから選択。
- **⚡ プリセット入力**: よく使うメモと金額のセットをワンタップで呼び出し。使用頻度順に自動ソート。
- **支払方法**: 支出のみ現金 / カードを選択（収入では非表示）。

### カレンダー画面
- **月間カレンダー**: 日ごとの収入（青）と支出（赤）を全桁表示。
- **日別データリスト**: 月内の全記録を一覧表示。タップで編集・削除。
- **月間サマリ**: 総収入・総支出・収支。

### レポート画面
- **カテゴリ別割合（円グラフ）**: スライスタップで詳細表示。
- **予算（クォータ）進捗**: カテゴリごとに「残額」「今日の目標額」「今日までの使用額」を表示。支出が0円でも予算設定があれば表示されます。
- **カテゴリリスト**: 合計金額と割合。タップで月間推移レポートへ。
- **来月のカード支払い額**: カード決済分の合計を自動集計。

### 設定画面
- **Google Drive クラウド同期**: Googleアカウントでログインし、JSON をクラウドへ同期。
- **カテゴリの管理・編集**: カスタムカラーで追加・編集。
- **固定収支の設定**: 家賃・サブスク等の毎月の固定支出／収入を登録。期間（開始日〜終了日）と引落し日を指定でき、一覧では期間も確認できます。
- **予算（クォータ）設定**: 全カテゴリの予算を一覧でインライン入力し、一括保存。
- **CSV エクスポート / インポート**。

## PC 版（Windows）

`PC-Application/` 配下。Google Drive for Desktop でマウントされたドライブ上の同期ファイルを直接読み書きします。Googleアカウントのログインは不要です。

### 入力タブ
日付・カテゴリ・金額・メモ・支払方法を指定して記録。プリセットからの呼び出しにも対応。

### カレンダータブ
月間カレンダーと日別リスト。各行から**編集・削除**ができます。編集ダイアログでは日付・カテゴリ・メモ・金額・支払方法を変更でき、日付は `YYYY-MM-DD` 形式、金額は数値であることを保存時に検証します（カンマ・全角数字・`¥`・`円` は自動で正規化）。

### レポートタブ
- カテゴリ別の円グラフと一覧。
- 予算に対する「残額 / 今日の目標 / 今日までの使用額」を表示（今月を表示しているときのみ日割りを計算）。
- 今月のカード利用額（来月支払い分）。
- カテゴリ名をクリックすると**カテゴリ別レポート**が開き、月別推移の棒グラフと全期間の履歴を確認できます。

### 設定タブ
- カテゴリの追加・削除
- プリセットの追加・削除
- 予算の**表示**（※編集は Android 版のみ）
- 定期収支（固定費）の追加・編集・削除
- ローカル / Drive への CSV エクスポート（※CSVインポートは Android 版のみ）
- JSON ファイルの手動再読み込み

### 起動方法

```bash
cd PC-Application
pip install -r requirements.txt
python main.py        # コンソールあり（デバッグ用）
```

日常利用ではコンソールの出ない `main.pyw` を使います（ショートカット推奨）。

同期ファイルのパスやウィンドウサイズは [`PC-Application/config.py`](PC-Application/config.py) に定義されています。**環境に合わせて `SYNC_FILE_PATH` を書き換えてください。**

```python
SYNC_FILE_PATH = os.path.join("G:\\", "マイドライブ", "家計簿", "kakeibo_sync.json")
```

起動時に対象ドライブが存在しない場合は警告を表示します（Drive for Desktop が未起動のまま起動してデータが空に見える事故を防ぐため）。

## データ同期の仕組み

Google Drive 上の **`kakeibo_sync.json` 1ファイル**を両クライアントが読み書きします。

| | Android | PC |
|---|---|---|
| アクセス方法 | Google Drive API v3（要ログイン） | マウント済みドライブを直接読み書き |
| 変更の取り込み | 起動時のサイレントサインイン後に同期 / データ更新時に自動同期 | 5秒ごとにファイルの更新時刻を監視して自動リロード |
| ローカル保持 | Room Database | メモリ上（保存のたびにJSONへ書き出し） |

マージは**レコード単位**で行われます。

- 各レコードが `syncId`（UUID）を持ち、これで突き合わせる
- 衝突時は `updatedAt` が新しい方を採用（last-writer-wins）
- 削除は物理削除せず `isDeleted` フラグで表現するため、削除も他端末へ伝播する
- 予算設定はカテゴリごとに1件が正しい状態のため、取り込み後に `updatedAt` が最新の1件へ集約される

## データ構造

Android では以下のテーブルとして Room に保持し、PC では同じ構造を JSON の配列として扱います。

| テーブル / JSONキー | 概要 |
|---|---|
| `categories` | カテゴリ（名前・色・タイプ・表示順） |
| `daily_data` / `dailyData` | 日次データ（日付・金額・メモ・カテゴリ・タイプ・支払方法） |
| `fixed_cost_settings` / `fixedCostSettings` | 固定費設定（金額・引落し日・期間） |
| `quota_settings` / `quotaSettings` | 予算設定（カテゴリごとの月間予算） |
| `presets` / `presets` | プリセット（メモ・金額・使用回数） |

全テーブルが共通して `syncId` / `updatedAt` / `isDeleted` を持ち、これが同期の土台になっています。

### 固定費の自動計上

両クライアントとも起動時に固定費設定を走査し、未計上の引落し日があれば日次データとして自動追加します。どこまで計上したかは設定側の `lastInsertedToDailyData` で管理しています。
