# 家庭簿アプリ (KakeiboGX)

Android向けの多機能家計簿アプリケーションです。日々の支出・収入の記録から、カレンダーごとの収支確認、カテゴリ別のグラフィカルな分析レポート、予算（クォータ）管理、プリセット入力、Google Driveを介した複数端末間でのJSON/CSV同期など、家計管理に必要な一連の機能を備えています。

## 主な機能一覧

### 1. 入力画面（Home / Input）
- **支出 / 収入の記録**: タブで直感的に切り替え可能。
- **日付選択**: カレンダー専用ダイアログから過去や未来の日付を簡単に指定。
- **金額入力（ビルトイン電卓）**: ボトムシート型の電卓UIでサクサク入力。
- **カテゴリ選択**: アイコンと色が設定されたカテゴリリストから選択（新たに視覚的なカラースタイリングを導入）。
- **⚡ プリセット入力**: よく使うメモと金額のセットをプリセット登録し、ワンタップで呼び出し可能。使用頻度順に自動ソートされます。

### 2. カレンダー画面（Calendar）
- **月間カレンダー表示**: 日ごとに収入（青字）と支出（赤字）をひと目で確認。数字が省略されず全桁表示されるよう改善。
- **日別データリスト**: その月の全記録を年月日付きでリスト表示。項目タップでデータの編集・削除が可能。
- **月間サマリ**: 月の総収入・総支出・収支計算を表示。

### 3. レポート画面（Report）
- **カテゴリ別割合（円グラフ）**: 支出（または収入）のカテゴリ別内訳を視覚化。スライスタップで詳細表示。
- **予算（クォータ）進捗管理**: カテゴリごとに「残額」「今日の目標額」「今日までの使用額」を表示。支出がなくても予算設定があればリストに表示されます。
- **カテゴリリスト**: 合計金額・割合を表示。タップで月間推移レポートへ遷移。
- **来月のカード支払い額表示**: クレジットカードで支払った金額の合計を自動計算して表示します。

### 4. その他・設定画面（Settings）
- **Google Drive クラウド同期**: Googleアカウントでログインし、JSON形式でクラウドへデータを同期。複数端末でのデータ共有・バックアップが可能です。
- **カテゴリの管理・編集**: カスタムカラーでカテゴリを自由に追加・編集。
- **固定収支の設定**: 毎月固定の支出（家賃、サブスク等）や収入を登録。リスト上でインライン編集が可能。
- **予算（クォータ）設定**: カテゴリごとに毎月の予算を一括で設定・保存できる専用画面。
- **CSVバックアップ**: 全データをCSVとしてエクスポート/インポート可能。

## 技術スタック (v2.0〜)
| 項目 | 技術 |
|---|---|
| 言語 | Kotlin |
| アーキテクチャ | MVVM + Repository パターン |
| UI | **Jetpack Compose (Edge-to-Edge デザイン)** |
| ナビゲーション | Compose Navigation |
| DB | Room Database (v2, マイグレーション対応) + Coroutines / Flow |
| クラウド同期 | Google Play Services Auth + Google Drive API REST v3 |
| グラフ | MPAndroidChart (円グラフ・棒グラフ) / Compose AndroidView ラッパー |

## データベース構成
| テーブル | 概要 |
|---|---|
| `categories` | カテゴリ（名前・色・タイプ・表示順） |
| `daily_data` | 日次データ（日付・金額・メモ・カテゴリ・タイプ・決済方法） |
| `fixed_cost_settings` | 固定費設定 |
| `quota_settings` | 予算設定 |
| `presets` | プリセット（メモ・金額・使用回数） |

## ビルド方法
1. Android Studio でプロジェクトを開く
2. Gradle Sync を実行 (最新のKotlinとComposeの依存関係を解決)
3. エミュレータまたは実機で `Run 'app'` を実行
   - **動作環境**: Android 8.0 (API 26) 以上
